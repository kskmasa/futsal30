# FUTSAL 30 ⚽

30日間でフットサルに向けた身体づくりを進める、個人用の日本語Webアプリです。

- **ダッシュボード**：今日の運動・食事チェック、達成率
- **トレーニング**：2026/11/03〜12/03の日別プラン、週切り替え、運動ガイド
- **食事**：昼はカップ麺＋サラダチキン、夕方は焼きおにぎり、夜は冷食のA/B/Cパターン
- **買い物**：1週間分の冷食の量とチェックリスト、コピー機能
- **記録**：ブラウザーの`localStorage`に保存（アカウント・外部送信なし）
- **PWA**：HTTPS環境でホーム画面への追加とオフライン表示が可能

HTML/CSS/JavaScriptのみ。ビルド、APIキー、npm installは不要です。

## GitHub Pagesで公開する

1. GitHubに新しい**Public**リポジトリ `futsal30` を作成します。
2. このフォルダーの**中身をすべて**、リポジトリの`main`ブランチ直下にアップロードします。`.github/workflows/pages.yml`も含めます。
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更します。
4. **Actions → Deploy Futsal 30 to GitHub Pages** の実行が成功すれば、通常 `https://<GitHubユーザー名>.github.io/futsal30/` で開けます。

GitHubの仕様や権限によってはActionsの実行を許可する必要があります。URLはPagesの設定画面でも確認できます。

## ローカル実行

```bash
python -m http.server 8000
```

http://localhost:8000 にアクセスします。ファイルを直接開いても主要な画面は動作しますが、PWA機能はHTTPサーバー・HTTPSが必要です。

## 運動・栄養に関する注意

このアプリは、会話で決めた個人向けの**目安**を記録するためのもので、診断や医学的な安全性を保証しません。運動負荷は疲労や体調に合わせて調整してください。胸部レントゲンで要精密検査となって未受診の場合、高強度トレーニングの前に医療機関に相談してください。胸痛、めまい、強い息切れなどが出たら運動を中止して受診してください。

食事量や栄養目標も開始時点の目安です。カロリー・たんぱく質は商品ごとの栄養成分表示で確認してください。

## データについて

運動の完了状況や買い物のチェックは、この端末のブラウザーの`localStorage`のみへ保存されます。別端末への同期はされません。プライベートブラウズやサイトデータ削除で記録が消えることがあります。
