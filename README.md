# FUTSAL 30 ⚽

フットサルに向けた30日間の身体づくりを記録する、スマートフォン対応のシンプルなWebアプリ。

## 機能

- **毎日約60分の活動プラン**：準備運動・筋トレ・フットワーク・ボールタッチ・ウォーキング・ストレッチの時間割と個別チェック。回復日もあります（疲れが強い日は短縮可）。
- **複数ユーザープロフィール**：ユーザー名、身長、体重、年齢（任意）を設定。ユーザーを切り替えると、運動・食事・体重の記録がそれぞれ切り替わります。
- **日次の体重記録**：日付・体重を保存、直近14件のグラフ、直近7日間の平均、過去データの削除。
- **食事日記**：昼・夕方・夜・運動後など、日付ごとに食べた食品を追加。カロリーとタンパク質を記録・集計。冷凍食品に加え、**プロテイン**をプリセットで選択できます。
- **夕食の3パターン**：チャーハン、ラーメン、パスタと単体の鶏肉・ブロッコリーなど。
- **買い物リスト**：1週間分の必要量を表示、買い物チェックとテキストコピー。
- **オフライン対応**：HTTPSではPWAとしてホーム画面に追加できます。

ビルド不要。HTML / CSS / JavaScriptのみです。

## 公開

GitHubの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
`main`へのpushで `.github/workflows/pages.yml` が静的サイトをデプロイします。

公開予定URL: https://kskmasa.github.io/futsal30/

## ローカル実行

```bash
python -m http.server 8000
```

ブラウザーで http://localhost:8000 を開いてください。

## 記録について

データは各ユーザーのアカウント認証・外部DBではなく、**その端末・ブラウザーのlocalStorage**に保存されます。別端末や別ブラウザーとの同期はありません。サイトデータ削除やプライベートブラウズで記録が失われる可能性があります。

以前のバージョンの記録は、新しいプロフィール保存形式の初回起動時に引き継がれます。

食事の栄養成分は食品プリセットでの概算値です。購入した商品の栄養表示に合わせて修正してください。体重に応じた摂取目標も計算上の暫定目安です。運動計画は体調や疲労に合わせて調整してください。
